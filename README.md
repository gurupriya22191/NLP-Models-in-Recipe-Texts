# NLP for Culinary Intelligence: Recipe Classification
A comprehensive study on classifying recipes into meal categories (Breakfast, Lunch, Dinner) using NLP. Includes a 6Lakh+ recipe dataset, EDA, and comparisons of Doc2Vec, CNN-BiGRU, and transformer-based models, with RecipeBERT fine-tuning achieving best results.

 • Constructed a large-scale NLP pipeline to classify 6 lakh+ recipes by category, cuisine,
 and course using structured metadata after Statistical analysis.
 
 • Engineered and evaluated multiple models—Doc2Vec + ML classifiers (Logistic Re
gression, SVM, Random Forest), CNN-BiGRU, and fine-tuned RecipeBERT—achieving
 72% top-1 accuracy on multi-label classification tasks.
 
 • Extended classification to 10 super-categories like Health/Diet, Calorie Content,
 Veg/Non-Veg, enabling scalable deployment for personalized recipe recommendations
